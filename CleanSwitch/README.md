# CleanSwitch

Local Windows desktop app that detects the current Windows install and
switches to the other boot for the next restart only.

It also has a Phase 2A **RETIRE SYSTEM** action that prepares the
Boot 1 → Recovery → Boot 2 handoff. It deletes nothing.

See the repository root `README.md` for full setup and usage, and `FUTURE.md`
for the phase status.
